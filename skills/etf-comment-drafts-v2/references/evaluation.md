# 同题对照与行为验证

用于修改前后或基础版与本版的对照。以下题目都是公开合成情境，产品和资料均为虚构；真实输入、生成结果、截图及用户评价保存在仓库外。

## 八个合成场景

| 场景 | 相同输入 | 观察行为 |
| --- | --- | --- |
| 1. 资料少、无原帖 | 主推虚构 ETF-A，跟踪广泛市场指数。无价格、新闻、分派、比较对象、交易经历和原帖。按默认写。 | 六类各四条；事件缺失时适当替代；关注点有差别，不虚构楼主或行情，也不全部变成“先了解”。 |
| 2. 两只都是自家产品 | ETF-A 跨行业、ETF-B 聚焦消费，均为自家产品，本轮主推 A。要六条有取舍的短评，不能踩自家。 | 能突出本轮要的定位，保留偏好；不嘲讽 B、不劝逃离 B，不编造 A 收益更高。 |
| 3. 已有前文的追问 | 原帖问 ETF-A 的成分调整；已有回复说明每半年调整，下一条问调整是一次执行还是分日完成。材料未给执行细节。只要三条可选接话。 | 不重复讲调整频率；回应执行问题，保留信息缺口；不杜撰已有人回答的结论。 |
| 4. 正文依赖素材 | 本轮提供虚构 ETF-A 的产品卡，卡上清楚显示名字及覆盖食品、家居；讨论正在问范围。要三条图注，不要蓝链。 | 正文可省略完整名称，但指代清楚；不把卡片当行情图，不另补蓝链或虚构表现。 |
| 5. 找讨论区但没有实时入口 | 虚构 ETF-A 覆盖行业甲的上游供应链；公司甲为其中一家。要讨论区、引入方式、文字与配图建议，没有提供帖子或可访问实时工具。 | 给有关联的候选和搜索方向；不声称已读当前热门帖，不造链接、热度或配图。 |
| 6. 素材与格式多样 | 用户提供虚构 ETF-A 成分表与指定日期的分时行情卡，未给日 K；要八条候选，按内容决定是否带素材。 | 分时与日 K 分清；各条有不同动作与关注点，允许纯文字；缺日 K 时列待补，不能谎称已附。 |
| 7. 私有案例边界 | 测试库含 approved 的短评、approved 的长文章、holdout 短评及只有 style_text 的旧记录；短评关联的图尚未读取。只写短评。 | 选短评参考、保留原声，默认不混长文章，不用 holdout；不猜图片内容，也不把 approved 当最喜欢或效果证明。 |
| 8. 用户覆盖默认 | 虚构 ETF-B 是行业主题产品。只写三条粤语确认问题，每条不超过三十字，无原帖和行情。 | 尊重三条、粤语、长度与问题类型；独立成立；不是普通话机械加粤语句尾，也不扩成二十四条。 |

场景 4、6 的素材测试应给双方同一份明确标为虚构的图片或完整文字说明。只有素材名称、没有可见内容时，验收其是否承认未读，而不是要求模型猜图。需要验证实际图像读取时使用单独的合成图附件。

## 公平比较

双方使用同一模型、同一产品资料、同一条数与输出要求。验证写作指令时给双方相同参考；验证完整流程时可以按各自选例方式运行，但记录参考材料差异，不能把额外私有资料带来的效果全部归功于提示词。

先检查可观察行为，再做自然度盲评：从每版抽取相同场景和数量，隐藏版本名，由用户标记“直接可用／轻改可用／需要重写”。完整构思按“正文＋接话位置＋素材建议”一起评价，不能只比较正文长度。

记录用户实际修改、踩自家或指代错误、素材误用以及同义重复。自动检查可找完全重复、缺字段或样本混入；语义立场、接话合理性和自然度仍需阅读，不用关键词出现次数替代判断。

## 私有参考与结果

`approved` 表示用户认可材料可作参考；`liked` 是明确偏好；互动数据、颜色或助手判断都不能自行升级成用户喜欢。保留部分参考作 `holdout`，生成与选择器不得读取其内容。

私有结果只报告本轮已验证的行为和仍待用户评价的自然度。不预设新版胜出，不报告未经用户评分的偏好胜率，不将公开合成题的通过视为全部平台或产品的效果证明。
