# 同题对照：验证文案是否更好用

用于比较旧版与本版，或比较本版修改前后。生成和评测结果保存在仓库外。下面只是公开的合成题目；不要把私有材料加入本文件。

## 三个固定场景

| 场景 | 相同输入 | 观察重点 |
| --- | --- | --- |
| 资料少、无原帖 | 虚构 ETF-A 跟踪广泛市场指数。没有价格、新闻、分派、比较对象或个人经历。按默认生成。 | 能否写出不同的具体关注点，避免一组都在“先了解” |
| 有比较和事件 | 虚构 ETF-A 覆盖广泛市场；ETF-B 聚焦单一行业。虚构情境中，周一公布了 A 的成分调整名单。没有收益数据或真实交易经历。按默认生成。 | 有态度的取舍、事件回应与提问能否各有内容，是否不当补出收益结论 |
| 明确覆盖默认 | 虚构 ETF-B 是行业主题基金。只写三条粤语提问，每条不超过三十字，无原帖和行情数据。 | 是否尊重类别、数量、语言和长度；问法是否自然且不重复 |

对比双方使用同一模型、同一产品资料和数量要求。验证提示词本身时，给双方相同参考样本；验证整个使用流程时，可以分别按各自的默认选例方式运行，但记录是否有一方多用了私有材料，避免归错原因。

## 小规模盲评

1. 默认场景先生成完整结果，用于检查分类和条数。人工评价时从每版抽取六条，覆盖不同类别，减少阅读负担。
2. 混排并隐藏版本名，由用户标记“直接可用／轻改可用／需要重写”。单独指出重复、太书面或太像标题的条目。第三个场景可全部查看。
3. 保留用户修改前后两句及其说明。它们比一句“更自然一点”更能指导下一次修改；未经允许不持久保存。
4. 对用户没有评价的结果标记为未评，不用代理的自评分补成用户选择。

## 看结果，而不只看测试是否通过

- **基本行为**：类别与数量、语言和明确限制是否满足，缺材料时是否正确替代。这些可自动检查。
- **可用性**：用户直接采用和轻改采用的情况，以及具体改了什么。由真实选择决定，不预设本版一定胜出。
- **整组重复**：记录同义重复和反复出现的空泛结尾。自动检查可找完全重复，语义重复仍需阅读。

私有样本中的 `holdout` 留作独立评价，不进入选例或提示词。公开题目属于可重复的基本检查，不能宣称它们证明了对未知产品或全部平台的泛化效果。没有用户评价时，只报告已验证的行为和仍待评价的自然度。
