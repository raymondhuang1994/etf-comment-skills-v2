# 合成写法对照

以下情境和文案均为公开教学新写，ETF-A、ETF-B 和公司甲均为虚构对象；不来自客户案例、截图或真实产品推广。示意不是用户偏好评分，不可将其中信息当作真实产品资料。私有合格案例与本轮明确要求优先。

读对照时同时看“说这句话需要什么上下文”。更短不必然更好，能接上当前讨论才有用。

| 虚构情境 | 较弱的写法 | 可采用的表达方向 | 取舍 |
| --- | --- | --- | --- |
| 清单明确写 ETF-A 同时覆盖食品和家居；读者刚看到清单 | ETF-A 覆盖丰富的消费领域，为用户创造多元配置价值。 | 食品、家居都算进来了，原来范围这么宽。 | 对刚读到的信息作反应，不拔高 |
| 前面问“成分多久换一次”；材料明确每半年调整 | 对于您提出的问题，该指数通常会以半年为周期进行调整。 | 半年调一次。 | 问题已经给足背景，不必重复 |
| 前文讨论名单调整，但没有说明执行方式 | 我认为有必要进一步研究和理解相关的调整规则。 | 换名单那天会一次调完吗？ | 把泛泛研究变成一个可回答的问题 |
| ETF-A 跨行业、ETF-B 聚焦消费，两者都是自家产品；本轮想突出 A 的覆盖 | B 太偏了，不如直接换成 A。 | A 跨行业，B 专门看消费。我这回想看的是前一种。 | 说明本轮偏好，不贬损另一只自家产品 |
| 用户提供一份可分享的成分表；所处讨论正在找相关公司 | 这份成分表信息丰富，值得大家深入学习与参考。 | 名单放这儿，找公司方便些。 | 分享资料有自己的动作，不必加宣传结论 |
| 素材中有可用的虚构产品介绍卡，显示 ETF-A 名称及消费行业定位，但未列子行业 | ETF-A 的消费覆盖十分广泛，ETF-A 值得持续关注。 | 图里这个也包括家电吗？ | 允许正文依赖图；没有图时需补清指代 |
| 公司甲属于虚构行业链，材料说明 ETF-A 覆盖该链条；该讨论正在问上游公司 | 既然大家关注公司甲，就不得不提 ETF-A 的独特投资价值。 | 顺着上游找，ETF-A 那张名单也能对照着看。 | 给出相关理由，不强扭话题 |
| 没有原帖，用户只给 ETF-A 的区域覆盖说明 | 楼主讲得很到位，这一点我完全赞同。 | 几个市场放在一张名单里，看起来省事些。 | 独立成立，不冒充已读前文 |
| 前面用粤语讨论名单中一个尚未解释的公司简称 | 我认为这个名称应该需要进行更加清楚的解释啦。 | 呢個縮寫即係邊間公司？ | 粤语语序自然，不能只改句尾 |
| 用户只给长期机制，没有当日行情 | 今日表现亮眼，ETF-A 必将带来更多惊喜。 | 规则写明白了，至少知道它按什么挑。 | 说材料已支持的机制，不补当天走势或保证 |
| 一批候选全是“我觉得 A 很好”“我认为 A 不错” | 逐句替换“不错、出色、优秀”。 | 分别回应覆盖、确认调整日期、问清简称、分享名单；保留适合本轮的动作。 | 差异来自想说的事，不靠近义词 |
| 用户提供未发生的参与意向，没有任何已实现交易 | 我持有以后每天都很安心。 | 按这张名单看，少了逐家公司挑的功夫。 | 描述机制或想法，不补个人交易故事 |

这些例子不构成固定模板。不要让每条都变成问句、都以“原来”开头、都赞省事，或都用图片含蓄提及产品。根据实际资料选择直接提及、简称、代码、蓝链、图注或纯文字。

筛选时对照三个问题：这句话回应了什么？读者能否从所在位置理解它？同批还有没有一句只换了词却在重复同一意思？产品立场另按主入口的本轮角色检查，不用“像真人”作为保留负面自家比较的理由。
